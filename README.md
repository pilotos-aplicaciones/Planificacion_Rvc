# Planificacion_Rvc

Aplicación web de planificación de obras de RVC (tipo SureTrak/Primavera, simplificada).

- **Frontend:** HTML + JavaScript (sin compilación), publicado con GitHub Pages.
- **Backend:** Firebase (Authentication con Google + Cloud Firestore), proyecto `rvc-planificacion`.
- **Configuración:** `js/firebase-config.js` es el único archivo a cambiar al migrar a la cuenta de la empresa.
- **Seguridad:** `firestore.rules` se copia en Firebase → Firestore → Reglas → Publicar.

Etapa transitoria en cuentas personales: **usar solo datos de prueba**.
